Step one, before any work on the screen

Run 1's last slide became four file edits

Run 1's retrospective claimed the prompts were missing parameters. Either that finding changes the skills, or it was decoration. Both skills were patched before they ran again.

SkillMissing parameterWhat got added
cep-product-managerTools · MCPA “Tools you have hands for” table: Figma MCP on the real file for ground truth — screenshot first, never describe a frame you haven't opened — hand competitor research to the research skill, cite paths via rg, and name the command that proves each criterion.
cep-product-managerSuccess“Done means”: an engineer builds from the file alone without one question, and every criterion names its command — otherwise hand it over labelled a draft and say which section is the reason.
design-competitor-researchTriggers“When this fires”: a landed brief is the trigger — plus stalled taste arguments, and consumer patterns about to be lifted into an operator tool.
design-competitor-researchThe barA review gate: the answer on slide two, counts not “most”, an “us” row, the trade named, the gaps written down, a next step.

Worth noticing: the PM was missing tools, the researcher was missing triggers — exactly the two parameters that make a chain a chain instead of three separate chats. The one that fetches evidence had no hands; the one that should fire on a hand-off didn't know a hand-off existed.
